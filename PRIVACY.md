# Nebula Hub extension privacy policy

Effective 10 October 2026

This policy covers the Nebula Hub browser extension. The extension adds and removes F95zone threads in the Nebula Hub desktop app, marks threads already in that library, and shows tag highlights from the app.

## Data stored on this computer

The extension stores its state in Chrome's local extension storage. That includes thread ids, the label color and notes used for library marks, pending adds (thread id and name) and pending removes, tag highlight settings, and the thread button placement. This data stays in the browser profile. The extension has no account system.

## Data shared with the desktop app

The extension talks only to the Nebula Hub app installed on the same computer, through Chrome's native messaging host. It sends thread ids and names when you add or remove a thread. The app sends back the library marks and tag highlights so the page can draw them. That exchange does not go to a server run for the extension.

## Site access

The extension runs only on f95zone.to. It reads the thread page in front of you so it can place marks, add and remove controls, and tag highlights. It does not read passwords, cookies, or payment data, and it does not keep a browsing history.

## Remote code and servers

The extension does not download or run code from the internet. It does not use analytics or advertising, and it does not sell or transfer data to anyone else.

The Nebula Hub desktop app is a separate program. When you run a library update in that app, the app requests public thread details from api.f95checker.dev using thread ids already in the library. The extension does not make that request.

## How long data is kept

Local extension data remains until you remove those threads, clear the extension's storage, or uninstall the extension. Uninstalling the extension removes its local storage. Data already saved by the desktop app stays in that app until you remove it there.

## Children

The extension is not directed at children.

## Changes

If this policy changes, the effective date above will change with it.
